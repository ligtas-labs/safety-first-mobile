# Product requirements — mobile

## Goal

Give Civil Engineering students repeatable offline construction safety practice on Android.

## Planned user journey

Download a reviewed tutorial or case, inspect a hazard, record a decision, review provisional feedback and synchronize later.

## Acceptance demonstration

In airplane mode save a decision, terminate the app and resume the same attempt. Retry a lost upload with the same ID. Start corrective practice and confirm the new ID preserves the original evidence.

Use synthetic accounts and record the build under test. Track delivery against the matching Linear stories.
